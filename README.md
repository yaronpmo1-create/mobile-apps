# אפליקציות אישיות לטלפון (Samsung S10e) - PWA ב-GitHub Pages

## 1. חת"ת יומי (מוכנה)
- כתובת: https://yaronpmo1-create.github.io/mobile-apps/limud-yomi/
- תיקייה: `limud-yomi` (שם התיקייה נשאר כדי שהכתובת לא תשתנה)
- מציגה תאריך עברי ולועזי, לימודים יומיים (חומש עם רש"י, תהילים עם הפרקים של היום, תניא, היום יום, משיח וגאולה) ושבועיים (שיחה, מאמר הרבי, מאמר אדמו"ר הזקן, מאמר אדמו"ר אחר).
- אפשר להוסיף נושאים (לחיצה ארוכה מוחקת). רצף ימים והיסטוריה של 30 יום. הכול נשמר בטלפון בלבד.
- היום העברי מתחלף בשקיעה: דורש אישור מיקום פעם אחת, שקיעה נטענת מ-Hebcal (חינם). בלי מיקום או אינטרנט - חצות.
- התקנה: Chrome בטלפון, פתיחת הכתובת, תפריט ⋮, "Add to Home screen".
- עדכון: שינוי בקבצים, `git push`; האפליקציה מתעדכנת בפתיחה הבאה עם אינטרנט.
- לא כלול עדיין: שם הפרשה ועמוד התניא של היום (דורש ספריית לוח שנה).

## 2. שעון יהודי (ממתינה להחלטה)
- התראות לפי זמני היום (Hebcal API, מקור חינמי ללא רישום).
- PWA לא יכולה התראה מדויקת כשהאפליקציה סגורה. ההמלצה: אפליקציית Android (APK עם Capacitor) לאפליקציה זו בלבד. ההחלטה טרם התקבלה.
